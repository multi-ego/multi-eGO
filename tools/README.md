# Useful multi-eGO Tools

- box_concentration: get simulation box sizes for a given concentration and number of molecules
- cmdata: calculate interatomic histograms from MD trajectories using GROMACS
- dihedral_histo: normalised periodic histograms of all gmx chi -all dihedrals on a fixed grid, and comparison between simulations
- domain_sectioner: merge probability matrix to account for multi-domain proteins priors
- dssp_content: per-residue secondary structure content from a gmx dssp dssp.dat file
- make_mat: get probability matrices and interaction distances from interatomic distances
